# Hi Genius｜英语学习与个人知识管理

Hi Genius 是一款免费的英语学习与个人知识管理工具，帮助你整理、检索、复习和练习英语学习资料。

## 📦 下载资源

**当前正式版本：V1.1.0**

- **应用：** 前往[最新正式发布页](https://github.com/potatoniniViber/hi-genius/releases/latest)，下载 `Hi_Genius.html`。
- **学习资料：** 查看[Hi Genius 学习资料库](./RESOURCE_LIBRARY.md)，按主题下载需要的 JSON 学习包和配套视频 ZIP。
- **使用条款：** [USAGE_TERMS.md](./USAGE_TERMS.md)。

> 学习包和视频资料会独立、逐个更新。历史资料不会因为应用版本更新而删除，所有已发布资料都可以在学习资料库中找到，不需要逐个翻找旧 Release。

## 🚀 快速开始

### 第一步：下载并打开应用
1. 前往[最新正式发布页](https://github.com/potatoniniViber/hi-genius/releases/latest)。
2. 下载 `Hi_Genius.html`。
3. 使用桌面版 Chrome 或 Edge 浏览器打开。

### 第二步：完成首次设置
- **新用户：** 首次打开应用时，按照页面提示设置初始累计学习天数。
- **已有用户：** 使用原来的浏览器和设备打开新版应用；更新前建议先导出个人完整备份。

### 第三步：导入学习包
1. 打开[学习资料库](./RESOURCE_LIBRARY.md)，找到感兴趣的主题。
2. 下载该主题对应的 JSON 学习包。
3. 在应用中进入「备份」→「导入学习包」。
4. 选择下载的 JSON 文件，按照页面提示完成导入。
5. 检查原文、笔记、标注及相关内容是否正常。

每个独立 JSON 学习包可以单独导入，不需要下载其他主题的资料。

**历史格式说明：** V1.0.0 首发学习资料是 ZIP 合集，需要先解压，再将里面的 JSON 文件逐个导入。V1.1.0 起新增学习包改为独立 JSON 文件。

### 第四步：按需关联视频
1. 在[学习资料库](./RESOURCE_LIBRARY.md)中找到对应主题的视频 ZIP。
2. 下载并解压视频 ZIP。
3. 在应用中进入「备份」→「视频授权」。
4. 根据应用提示重新关联视频文件夹。

如果暂时不需要视频，可以跳过此步骤。没有新增或更换视频资料时，也不需要为了应用版本更新而重新下载全部视频。

## 🔄 更新应用

### 已有用户
1. 更新前，先在旧版应用中导出个人完整备份，并妥善保存。
2. 前往[最新正式发布页](https://github.com/potatoniniViber/hi-genius/releases/latest)，下载最新版 `Hi_Genius.html` 并打开。
3. 如需恢复个人数据，通过「备份」→「导入完整备份」恢复。注意：完整备份导入可能覆盖当前数据，请确认文件正确。
4. 打开[学习资料库](./RESOURCE_LIBRARY.md)，只下载并导入新增或自己尚未导入的学习包。
5. 如果有新增或更新的视频资料，再下载对应视频 ZIP、解压并通过「视频授权」重新关联。

**更新应用和更新学习资料是两件事。** 更新 HTML 不代表新增学习笔记已经导入；需要单独下载并导入对应的 JSON 学习包。已经导入的历史学习包无需因为应用升级而重复下载。

## ⚠️ 数据安全提醒
- 请定期导出个人完整备份，并妥善保存。
- 更新应用前，建议先备份个人数据。
- 导入完整备份前，请确认是否需要保留当前笔记；完整备份导入可能覆盖当前数据。
- 学习资料包不等于个人数据备份。
- 不要将包含个人隐私信息的完整备份上传到公开仓库。
