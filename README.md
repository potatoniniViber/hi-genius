# Hi Genius｜英语学习与个人知识管理

Hi Genius 是一款免费的英语学习与个人知识管理工具，帮助你整理、检索、复习和练习英语学习资料。

## 📦 下载资源

**当前版本：V1.0.0**

所有下载文件请前往 [V1.0.0 正式发布页](https://github.com/potatoniniViber/hi-genius/releases/tag/V1.0.0)。

- **应用：** Hi_Genius.html
- **学习包：** Hi_Genius_Learning_Packs_v1.0.0.zip
- **视频资料：** Hi_Genius_Video_Pack_v1.0.0.zip

## 🚀 快速开始

### 第一步：下载并打开应用

1. 从正式发布页下载 `Hi_Genius.html`。
2. 使用桌面版 Chrome 或 Edge 浏览器打开。
3. 无需注册账号，即可开始使用。

### 第二步：导入学习资料

1. 下载 `Hi_Genius_Learning_Packs_v1.0.0.zip`。
2. 解压 ZIP 文件，获取里面的 JSON 学习包。
3. 在应用中进入「备份」→「导入学习包」。
4. 选择 JSON 文件，按照页面提示完成导入。
5. 检查原文、笔记、标注及相关内容是否正常。

如果 ZIP 中包含多个学习包，请分别导入。

### 第三步：关联视频

1. 下载视频 ZIP 并解压。
2. 在应用中进入「备份」→「视频授权」。
3. 根据应用提示重新关联视频文件夹。

如果没有使用视频资料，可以跳过此步骤。

## 🔄 更新应用

### 已有用户

1. 更新前，先在旧版应用中导出个人完整备份。
2. 下载最新版本的 HTML 应用并打开。
3. 如需恢复个人数据，通过「备份」→「导入完整备份」恢复。注意：完整备份导入可能覆盖当前数据，请确认文件正确。
4. 下载并解压最新学习包 ZIP。
5. 通过「备份」→「导入学习包」导入新增内容。

**更新应用和更新学习资料是两件事。** 更新 HTML 不代表最新笔记已经导入；需要导入对应的学习包才能查看新增内容。

### 新用户

下载应用后，直接导入需要的学习包即可开始学习。

## ⚠️ 数据安全提醒

- 请定期导出个人完整备份，并妥善保存。
- 导入完整备份前，请确认是否需要保留当前笔记。
- 更新应用前，建议先备份个人数据。
- 不要将包含个人隐私信息的完整备份上传到公开仓库。
