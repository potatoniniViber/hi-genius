# Hi Genius｜英语学习与个人知识管理

Hi Genius 是一款免费的英语学习与个人知识管理工具，帮助你整理、检索、复习和练习英语学习资料。

## 📦 下载资源

- **应用：** [Hi_Genius.html](./Hi_Genius.html)
- **初始学习资料：** [Hi_Genius_Starter_Data.json](./Hi_Genius_Starter_Data.json)
- **视频资料包：** 请前往本项目的 Releases 页面下载。

## 🚀 快速开始

### 第一步：下载并打开应用

1. 下载 `Hi_Genius.html`。
2. 使用桌面版 Chrome 或 Edge 浏览器打开。
3. 无需注册账号，即可开始使用。

### 第二步：导入初始学习资料

1. 下载 `Hi_Genius_Starter_Data.json`。
2. 打开 Hi Genius，进入应用的备份/导入功能。
3. 选择 JSON 文件，按照页面提示完成导入。
4. 检查原文、笔记、标注和图片是否正常。

**注意：** 初始资料包用于首次导入。如果应用提示将恢复完整备份，请先确认当前数据是否需要保留，避免覆盖已有笔记。

### 第三步：恢复视频

1. 从 Releases 页面下载视频 ZIP。
2. 将 ZIP 解压到一个文件夹。
3. 保留视频原始文件名，不要随意重命名。
4. 在应用中进入「备份」→「视频授权」→「授权文件夹」。
5. 选择解压后的视频文件夹，并检查视频是否成功匹配和播放。

具体操作以当前应用界面为准。文件夹授权需要浏览器支持。

## 💾 数据保存与备份

- 个人笔记保存在当前浏览器的本地存储中，不会自动同步到其他设备。
- 更换浏览器、设备或清理浏览器数据，可能导致无法直接读取原有笔记。
- 建议定期导出完整备份，并保存到电脑或其他安全位置。
- **更新应用前，请先从旧版本导出个人完整备份。** 下载新版后，再按应用提示恢复数据，并检查是否正常。
- 不要将包含个人笔记或敏感信息的完整备份上传到公开仓库。

## 🔄 版本更新

更新时，请先备份个人数据，再下载新版应用。不要假定不同版本之间会自动继承数据。
